# 🚀 Tracker: AI Budget App

**Описание проекта:** Конкурентное приложение для ведения личного бюджета.
**Главная фича (Киллер-фича):** Ввод расходов голосом. Пользователь надиктовывает трату, AI распознает речь, парсит смысл и автоматически категоризирует покупку.
**Стек технологий:** React (Vite), Node.js (NestJS), PostgreSQL, Prisma ORM, OpenAI API (Whisper + GPT/Claude), Capacitor (для мобильной версии), Local-first (в будущем).
