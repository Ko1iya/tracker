# budget-web — фронтенд Tracker: AI Budget App

Веб-клиент приложения для учёта личного бюджета: лента расходов, ручной ввод
трат, в планах — голосовой ввод через AI. Стек: **React 19 + Vite +
TypeScript**, Tailwind CSS, shadcn/ui, React Router, TanStack Query, axios.

## 📋 План разработки (роадмап)

Этапы всего проекта (бэкенд + фронтенд) ведутся **в одном месте** — в
репозитории бэкенда `budget-api`, чтобы план не дублировался и не расходился:

➡️ **[`../budget-api/README.md`](../budget-api/README.md)** — единый
план-роадмап и статус по этапам.

Актуальная карта файлов и маршрутов — в [`SPEC.md`](./SPEC.md).
